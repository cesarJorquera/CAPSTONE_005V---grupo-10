# Evidencias del proyecto

Esta carpeta reúne el sistema, su documentación técnica y la presentación final del Proyecto CAPSTONE.

## Contenido

- **Aplicación:** código fuente Vue y configuración de la aplicación en [`Evidencias de sistema/Aplicación`](./Evidencias%20de%20sistema/Aplicaci%C3%B3n/README.md).
- **Base de datos:** migraciones Supabase y referencia al modelo de datos en [`Evidencias de sistema/Base de datos`](./Evidencias%20de%20sistema/Base%20de%20datos/README.md).
- **Documentación:** planificación, requisitos, arquitectura, pruebas y manuales en [`Evidencias de documentación`](./Evidencias%20de%20documentaci%C3%B3n/README.md).
- **Informe final e innovación:** el informe técnico final y la visión de producto e innovación están dentro de `Evidencias de documentación`.
- **Presentación:** guardar aquí el archivo final de exposición, con el nombre solicitado por la guía de entrega.

La aplicación publicada está en [leo-perfecto.netlify.app](https://leo-perfecto.netlify.app/). Antes de la exposición, comprobar inicio de sesión, flujo completo del usuario y datos del dashboard en el entorno remoto.
